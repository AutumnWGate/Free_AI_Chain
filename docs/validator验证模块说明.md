# validator验证模块说明

## 0. 验证模块目标
1. 模块位置：src/ledger/validator目录下
2. 验证模块根据业务类型分为铸造验证、交易验证。
3. 验证成功后，触发更新接收方的余额，同时更新数据库、默克尔树、区块链。

## 1. 分业务类型设计验证逻辑

### 1.1 针对early_donate铸造代币的验证规则
第一步：获取铸造发起者地址
第二步：判断铸造发起者地址是否在管理员铸造白名单中
    如果铸造发起者地址不在管理员铸造白名单中，则拒绝铸造。    
第三步：铸造发起者地址在管理员铸造白名单中，则验证铸造发起者签名。
    如果铸造发起者签名不正确，则拒绝铸造。
第四步：验证铸造信息格式。
    如果铸造信息格式不正确，则拒绝铸造。
    验证铸造接受地址是否存在，如果不存在，则拒绝铸造。
第五步：第二步第三步和铸造信息全部正确，则铸造成功，更新接受者地址的余额，同时更新数据库、默克尔树、区块链。


## 2. 验证模块目录结构
src/ledger/validator/
